# Escape Room Funktionslabor

Digitaler Escape Room für Mathematik, Jahrgangsstufe 11 (Gymnasium Bayern): Verschieben und Strecken von Funktionsgraphen.

Acht Stationen, Lösungswort am Ende. Die Seite läuft komplett im Browser, Fortschritt wird lokal im Gerät gespeichert.

## Der Spiegelsaal (`spiegelsaal.html`)

Kurzer Escape Room zu Lambacher Schweizer 11 (Bayern), S. 25, Aufgabe 4: Spiegeln, Strecken und Verschieben von f(x) = 1/(x − 2) + 1. Drei Räume (a–c), Lösungswort am Ende.
